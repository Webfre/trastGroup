# TrastGroup Contract: стек, стиль и схема страниц

Дата подготовки: 31.07.2026

## 1. Технический стек

Проект планируется делать на:

- React
- Vite
- желательно TypeScript
- компонентная архитектура
- адаптивная верстка desktop / tablet / mobile

Рекомендуемый UI-стек:

- Tailwind CSS или CSS Modules с глобальными CSS-переменными;
- Framer Motion / Motion для аккуратных анимаций;
- shadcn/ui или собственные компоненты на Radix primitives, если понадобится надежная база для форм, модалок, табов и аккордеонов;
- Swiper / Embla Carousel для слайдеров писем, фото и логотипов.

Важно: готовые блоки из ReactBits, Aceternity, 21st.dev и Componentry использовать точечно, не собирать сайт как набор чужих шаблонов.

## 2. Глобальная визуальная система

Главный визуальный ориентир: https://a101.ru/

Что берем как принцип:

- светлая база;
- много воздуха;
- крупная уверенная типографика;
- аккуратные сетки;
- реальные фото команды;
- сдержанный красный акцент;
- технологичная, но деловая подача;
- плавные микроанимации без визуального шума.

## 3. Глобальная палитра

Палитра должна быть задана глобально на весь проект через CSS-переменные или дизайн-токены.

```css
:root {
  --color-brand-red: #e62c34;
  --color-brand-black: #1d1d1b;
  --color-white: #ffffff;

  --color-bg: #f7f7f5;
  --color-surface: #ffffff;
  --color-surface-muted: #f1f2f4;
  --color-text: #1b1d24;
  --color-text-muted: #5d626d;
  --color-border: #e5e7eb;

  --color-dark-section: #161616;
  --color-dark-text: #ffffff;
  --color-success: #2f8f5b;
  --color-warning: #b87914;

  --radius-xs: 4px;
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;

  --shadow-soft: 0 16px 40px rgba(17, 24, 39, 0.08);
}
```

Правила палитры:

- красный использовать как акцент: CTA, маркеры, активные состояния, важные цифры;
- черный использовать для текста, логотипа, отдельных контрастных секций;
- не делать сайт полностью красно-черным;
- фон преимущественно светлый;
- темные секции использовать точечно: hero-overlay, блок цифр, финальный CTA или акцентный блок.

## 4. Шрифты и скругления

Шрифты:

- основной вариант: `Onest`;
- запасной вариант: `Manrope`;
- системный fallback: `Inter`, `Arial`, `sans-serif`;
- `Euclid Circular A` использовать только при наличии лицензии.

Скругления:

- основные карточки: 8-12px;
- крупные фото/секции: 12-16px;
- кнопки: 8-12px;
- не делать чрезмерно "пухлые" pill-кнопки везде, сайт должен оставаться деловым.

## 5. Анимации и UI-референсы

### ReactBits

Использовать для:

- плавного появления блоков при скролле;
- счетчиков цифр;
- аккуратных text reveal-эффектов;
- hover-анимаций карточек;
- animated list для этапов процесса.

Не использовать:

- тяжелые WebGL-фоны;
- космические/игровые эффекты;
- яркие эффекты, которые спорят с B2B-тематикой.

### Aceternity UI

Лучше всего подходят:

- Hero Sections;
- Bento Grid;
- Timeline;
- Stats Sections;
- Logo Cloud;
- Team Sections;
- Testimonials / Carousel;
- File Upload;
- Contact Sections;
- FAQ;
- World Map, если получится адаптировать под географию России.

### 21st.dev

Использовать как источник:

- готовых вариантов карточек услуг;
- number ticker;
- form components;
- навигации;
- аккуратных marketing sections;
- shadcn-compatible блоков.

### Componentry

Использовать точечно:

- hover states;
- небольшие motion-эффекты;
- интерактивные акценты в hero или CTA;
- не брать тяжелую декоративную анимацию.

## 6. Общая структура сайта

MVP-структура:

1. Главная
2. Тендерное сопровождение

## 7. Главная страница

Задача: за 10-15 секунд объяснить, что компания сопровождает закупки и исполнение контрактов по всей России.

- Логотип
- Навигация
- Телефон
- Иконки Telegram / WhatsApp
- CTA "Получить консультацию"
- Мобильное меню

### Hero

Контент:

- H1: `Сопровождаем закупки от первой заявки до исполнения контракта`
- подзаголовок про 44-ФЗ, 223-ФЗ, БРИФ, коммерческие закупки и поставки;
- CTA:
  - `Получить консультацию`
  - `Отправить заявку`
- реальное фото команды.

Анимация:

- мягкое появление текста;
- легкое движение/маска фото;
- без тяжелого фона.

### Быстрая строка доверия

Плитки/теги:

- 44-ФЗ
- 223-ФЗ
- ГК "Росатом" / БРИФ
- Коммерческие закупки
- ЭТП
- Поставки по России

### Два направления работы

Крупный блок из двух карточек:

- Тендерное сопровождение
- Поставки и исполнение контрактов

У каждой карточки:

- короткое описание;
- 4-5 пунктов;
- ссылка на страницу направления.

### Путь клиента

Timeline в 5-6 шагов:

1. Анализ ниши, закупки и рисков
2. Регистрация, ЭТП, ЕИС, БРИФ, подпись

4. Торги, переговоры, контракт
5. Поставка, логистика, исполнение
6. Отчетность и сопровождение

### Что берем на себя

Сетка услуг:

- мониторинг тендеров;
- анализ документации;
- регистрация в ЕИС/ЭТП;
- электронная подпись;
- банковские гарантии;
- подготовка заявки;
- БРИФ и закрытые площадки;
- жалобы в ФАС;
- поставки и логистика.

### Почему выбирают нас

Пункты:

- 8 лет в тендерах, если цифра подтверждается;
- понимаем процесс изнутри;
- полный охват 44-ФЗ, 223-ФЗ и коммерческих закупок;
- работаем с закрытыми и специализированными площадками;
- в команде тендерные специалисты, бухгалтер, юрист, логист;
- работаем по всей России онлайн.

### Блок цифр

Пока placeholders до подтверждения:

- сопровожденных закупок;
- клиентов;
- сумма контрактов;
- регионов работы;
- площадок.

Анимация:

- number ticker;
- появление при скролле.

### Команда

- 5 карточек сотрудников;
- фото;
- имя;
- роль;

### Клиенты / закупки крупнейших компаний

- не писать "наши клиенты", пока не подтверждено.

### Благодарственные письма

- слайдер;
- фото письма;
- описание;

### Финальная форма заявки

## 8. Страница "Тендерное сопровождение"

Задача: подробно раскрыть ключевую услугу и привести пользователя к заявке.

### Hero услуги

- H1: `Тендерное сопровождение по 44-ФЗ, 223-ФЗ и коммерческим закупкам`
- подзаголовок про разовое участие и долгосрочное сопровождение;
- CTA `Обсудить закупку`.

### Форматы работы

Карточки:

- Разовое участие в закупке
- Долгосрочное сопровождение
- Участие "под ключ"
- Консультации и срочная проверка

### Что входит в сопровождение

Сетка/аккордеон:

- анализ закупки;
- мониторинг тендеров;
- оценка рентабельности;
- регистрация в ЕИС и на ЭТП;
- оформление электронной подписи;
- подготовка документов;
- банковские гарантии;
- сопровождение торгов;
- переговоры и контракт;
- спорные ситуации и ФАС.

### Площадки и закупки

Группы:

- 44-ФЗ
- 223-ФЗ
- коммерческие закупки
- БРИФ / Росатом
- ЭТПРФ
- АСТ ГОЗ
- Закупки.Стартер / ЭТП ГПБ
- SAP SRM
- Фосагро
- СИБУР

### Процесс работы

Timeline:

1. Получаем задачу и документы
2. Проверяем требования и риски
3. Готовим заявку
4. Согласуем подачу
5. Сопровождаем торги
6. Ведем до договора/исполнения

### Блок "Где чаще всего ошибаются"

- сроки;
- требования;
- обеспечение;
- электронная подпись;
- спецификация;
- подтверждение опыта;
- документы поставки.

### CTA с прикреплением документации

Форма:

- имя;
- телефон;
- email;
- ссылка на закупку;
- файл документации;
- комментарий.

## 14. Адаптивность

Обязательные требования:

- все страницы должны корректно работать на 320px+;
- меню превращается в мобильное;
- таблицы/сетки перестраиваются в одну колонку;
- hero-фото кадрируется отдельно для mobile;
- CTA доступны без горизонтального скролла;
- формы удобны на мобильных;
- слайдеры работают свайпом;
- текст не должен налезать на изображения и кнопки.
