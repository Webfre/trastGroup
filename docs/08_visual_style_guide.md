# TrastGroup Contract: современный стиль и палитра

Дата подготовки: 31.07.2026

## 1. Общий стиль

Сайт делаем в современном B2B-стиле: чисто, спокойно, технологично и уверенно. Не делаем агрессивный лендинг и не уходим в тяжелый юридический шаблон.

Главное ощущение:

- надежность;
- точность;
- контроль процесса;
- команда практиков;
- современный деловой сервис.

Главный визуальный ориентир: A101.

От A101 берем не копию дизайна, а принципы:

- много воздуха;
- светлая база;
- крупная типографика;
- аккуратные карточки;
- качественные фото;
- сдержанный красный акцент;
- мягкие интерактивные состояния;
- чистая навигация.

## 2. Палитра

Палитру задаем глобально через CSS-переменные/дизайн-токены.

### Основные цвета

```css
:root {
  --brand-red: #e62c34;
  --brand-black: #1d1d1b;
  --white: #ffffff;

  --bg-main: #f7f7f5;
  --bg-soft: #f1f2f4;
  --surface: #ffffff;

  --text-main: #1b1d24;
  --text-muted: #5d626d;
  --text-soft: #858b96;

  --border: #e5e7eb;
  --border-strong: #d1d5db;

  --dark-section: #161616;
  --dark-section-soft: #202124;

  --success: #2f8f5b;
  --warning: #b87914;
}
```

### Роли цветов

- Красный `#e62c34`: кнопки, активные элементы, маркеры, важные цифры, hover-состояния.
- Черный `#1d1d1b`: логотип, заголовки, контрастные секции.
- Светлый фон `#f7f7f5`: основа страниц.
- Белый `#ffffff`: карточки, формы, модальные окна.
- Серые: вторичный текст, границы, подписи, неактивные элементы.

### Что не делаем

- Не заливаем весь сайт красно-черной палитрой.
- Не используем много градиентов.
- Не делаем кислотные hover-эффекты.
- Не используем декоративные фоны ради декора.

## 3. Типографика

Основной шрифт:

- `Onest`

Запасные:

- `Manrope`
- `Inter`
- `Arial`
- `sans-serif`

`Euclid Circular A` можно использовать только при наличии лицензии.

Принцип:

- заголовки крупные, уверенные, без декоративности;
- тексты короткие и сканируемые;
- много микрозаголовков и смысловых подписей;
- минимум длинных абзацев.

## 4. Скругления и поверхности

Радиусы:

```css
:root {
  --radius-xs: 4px;
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;
}
```

Правила:

- карточки: 8-12px;
- большие фото: 12-16px;
- формы: 12px;
- кнопки: 8-12px;
- не делать слишком "пухлые" элементы, стиль должен быть деловым.

Тени:

- минимальные;
- лучше использовать границы, фоновые отличия и аккуратные hover-состояния;
- крупные тяжелые тени не нужны.

## 5. Сетка и layout

База:

- max-width контента: 1180-1280px;
- крупные секции с вертикальными отступами;
- 12-колоночная логика на desktop;
- 2 колонки на tablet;
- 1 колонка на mobile.

Главная должна читаться как маршрут:

1. Кто мы и чем помогаем.
2. Два направления.
3. Как ведем клиента.
4. Что берем на себя.
5. Почему нам доверяют.
6. Команда.
7. Доказательства.
8. Заявка.

## 6. Фото

Фото команды - ключевой визуальный актив.

Использование:

- hero;
- "О компании";
- команда;
- процесс/рабочие встречи;
- фоновые акценты в CTA.

Правила:

- не затемнять фото слишком сильно;
- не делать фото декоративной подложкой без смысла;
- кадрировать отдельно под desktop/mobile;
- сохранить ощущение реальной команды, не превращать в сток.

## 7. Анимации

Анимации должны быть дорогими и тихими.

Подходят:

- плавное появление блоков;
- легкий parallax для фото;
- number ticker для цифр;
- reveal для ключевых заголовков;
- hover-карточки;
- timeline-анимация;
- мягкий carousel для писем/логотипов.

Не подходят:

- WebGL ради эффекта;
- космические/игровые фоны;
- sparkles/meteors/vortex;
- слишком активная типографика;
- анимации, которые мешают читать.

## 8. Какие референсы берем

### A101

Основной источник визуального направления:

- спокойный современный стиль;
- светлая база;
- крупная типографика;
- аккуратные сетки;
- премиальность без шума.

Берем:

- аккуратные hover-интеракции.

### Aceternity

Берем идеи:

- Timeline;
- Stats Sections;
- Logo Cloud;
- Team Sections;
- Contact Sections;

### 21st.dev

Берем:

- варианты карточек;
- формы;
- number ticker;

Берем:

- polished hover states;
- небольшие motion-интеракции;
- не берем декоративную перегрузку.

## 9. UI-настроение по блокам

Hero:

- крупный заголовок;
- реальное фото;
- аккуратные CTA;
- строка доверия с 44-ФЗ, 223-ФЗ, БРИФ, ЭТП.

Услуги:

- bento/grid;
- короткие формулировки;
- активный hover.

Процесс:

- timeline;
- можно использовать scroll reveal.

Цифры:

- темный или светлый контрастный блок;
- number ticker;
- минимум текста.

Команда:

- фото крупнее, подписи короче;
- карточки спокойные, без лишних эффектов.

Письма:

- слайдер;
- изображение + краткая подпись;
- модалка для просмотра.

Формы:

- чистые поля;
- понятный тип обращения;
- file upload для документации/спецификации.

## 10. Итоговое направление

Делаем сайт в стиле:

`современный B2B / procurement / legal-tech / industrial supply`

Но визуально:

`светло, лаконично, с реальными фото, красным акцентом и аккуратными анимациями`

Главный принцип: каждый эффект и блок должен помогать понять процесс, доказать опыт или отправить заявку.
