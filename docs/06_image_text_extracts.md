## 3. Контентные выводы для ТЗ

- На сайте можно использовать формулировку про два формата работы: разовое участие и долгосрочное сопровождение.
- Нужно явно показать работу по 44-ФЗ, 223-ФЗ и коммерческим закупкам.
- БРИФ/Росатом стоит выделить как отдельную компетенцию, если заказчик подтверждает приоритет направления.
- "8 лет в тендерах" можно использовать в блоке цифр только после подтверждения заказчиком.
- "Работаем по всей России. Онлайн. Быстро. Чётко." подходит как короткая поддерживающая строка для hero или блока географии.
- Командный состав из макета: тендерные специалисты, бухгалтер, юрист, логист.
- Для блока площадок нужно предусмотреть закрытые и специализированные площадки: БРИФ, ЭТПРФ, АСТ ГОЗ, Закупки.Стартер, ЭТП ГПБ, SAP SRM, Фосагро, СИБУР.
- Для раздела БРИФ полезны отдельные подпункты: аккредитация, каталог продукции, поиск отборов, консультации, опыт поставок, подача заявки на отбор.
