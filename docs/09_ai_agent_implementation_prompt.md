ОСНОВНОЙ ВЕКТОР ПРОДУКТА:

TrastGroup Contract - это современная B2B-команда полного цикла для тендерного сопровождения и исполнения контрактов через поставки и логистику.

Сайт должен показывать не просто "помощь в тендерах", а весь путь:
- анализ закупки, ниши и рисков;
- регистрация в ЕИС, ЭТП, БРИФ;
- электронная подпись;
- подготовка заявки;
- банковские гарантии;
- торги, переговоры и контракт;
- спорные ситуации и ФАС;
- поставка, логистика и исполнение.

ТЕХНИЧЕСКИЙ СТЕК:

- React
- Vite
- желательно TypeScript
- адаптивная верстка desktop / tablet / mobile
- компонентная архитектура
- глобальные CSS-переменные или дизайн-токены

Можно использовать:
- Tailwind CSS или CSS Modules;
- Framer Motion / Motion для аккуратных анимаций;
- shadcn/ui или Radix primitives, если нужен надежный UI-фундамент;
- Swiper или Embla Carousel для слайдеров.

СТИЛЬ:

Главный визуальный ориентир - A101:
- светлая база;
- много воздуха;
- крупная типографика;
- реальные фото команды;
- сдержанный красный акцент;
- строгие сетки;
- деловой современный интерфейс.

Палитра должна быть глобальной:
- фирменный красный: #e62c34;
- фирменный черный: #1d1d1b;
- основной фон: #f7f7f5;
- поверхность карточек: #ffffff;
- основной текст: #1b1d24;
- вторичный текст: #5d626d;
- границы: #e5e7eb;
- темная секция: #161616.

Шрифты:
- основной: Onest;
- запасной: Manrope или Inter;
- Euclid Circular A использовать только при наличии лицензии.

Скругления:
- карточки 8-12px;
- крупные фото 12-16px;
- кнопки 8-12px;
- не делать интерфейс слишком "пухлым".

UI-РЕФЕРЕНСЫ:

Используй ReactBits, Aceternity UI, 21st.dev и Componentry только точечно:
- timeline;
- stats / number ticker;
- logo cloud;
- team cards;
- carousel благодарственных писем;
- file upload;
- contact form;
- мягкие reveal/hover-анимации.

Не используй:
- тяжелые WebGL-фоны;
- космические эффекты;
- sparkles, meteors, vortex;
- слишком активную типографику;
- шаблоны целиком без адаптации.
